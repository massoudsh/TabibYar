# ایشو #25 — انتخاب ۳ تا ۵ پزشک پایلوت در ۲ تخصص انتخاب‌شده

> انتخاب واقعی پزشکان (افراد مشخص با نام/شماره تماس) اقدامی میدانی و ارتباطی است که
> باید توسط تیم محصول/فروش انجام شود؛ نمی‌توان پزشک واقعی را از طریق کد یا این نشست
> «انتخاب» کرد. آنچه در این سند آماده شده، **چارچوب اجرایی قابل‌استفادهٔ فوری** برای
> انجام آن انتخاب توسط تیم است.

## معیارهای انتخاب پزشک پایلوت

1. تخصص: داخلی/بیماری‌های مزمن **یا** پوست (طبق `docs/phase1-mvp.md`).
2. حجم ویزیت روزانه متوسط تا بالا (برای دیدن ارزش سریع‌تر ابزار).
3. تمایل به ثبت خلاصهٔ متنی/صوتی هر ویزیت (حداقل تعهد زمانی pilotها).
4. دسترسی به موبایل/کامپیوتر با اتصال اینترنت پایدار حین/بعد ویزیت.
5. ترجیحاً آشنا با ابزارهای دیجیتال (کاهش اصطکاک onboarding).

## چک‌لیست اجرایی برای تیم (قابل استفادهٔ فوری)

- [ ] تهیهٔ لیست ۱۰-۱۵ پزشک کاندید (۵-۸ داخلی + ۵-۷ پوست) از شبکهٔ ارتباطی موجود.
- [ ] تماس اولیه + توضیح مختصر محصول (رجوع به README.md ریشهٔ پروژه برای متن معرفی).
- [ ] ارسال فرم رضایت همکاری پایلوت (جدا از رضایت بیمار #20؛ رضایت *پزشک* برای همکاری در پایلوت).
- [ ] برنامه‌ریزی جلسهٔ ۳۰ دقیقه‌ای onboarding + ساخت حساب (`npm run seed` برای هر کلینیک).
- [ ] تعیین بازهٔ پایلوت (پیشنهاد: ۲-۴ هفته) و تاریخ جمع‌آوری فیدبک اول (#27).

## وضعیت

این ایشو نیازمند اقدام انسانی (تماس و هماهنگی واقعی با پزشکان) است و در این نشست
کدنویسی نمی‌تواند «بسته» شود مگر به‌عنوان آمادگی چارچوب/ابزار (که انجام شد:
`src/db/seed.js` برای onboarding سریع هر کلینیک پایلوت).
