## اپیک ۱ — Ingestion & Structuring Pipeline

- **#1** [epic] پایپ‌لاین تبدیل خلاصهٔ صوتی/متنی پزشک به JSON ساختاریافته `p0`
- **#2** [feature] ارزیابی و انتخاب سرویس STT فارسی با دقت قابل‌قبول روی اصطلاحات پزشکی مخلوط فارسی/لاتین `p0` `research`
- **#3** [feature] طراحی JSON Schema برای خروجی ساختاریافته (شرح‌حال/یافته/تشخیص پیشنهادی/برنامه درمان/توصیه/هشدار/پیگیری) `p0`
- **#4** [feature] پرامپت اختصاصی دامنهٔ پزشکی فارسی برای هر یک از ۲ تخصص فاز اول `p0`
- **#5** [feature] مکانیزم علامت‌گذاری خودکار موارد مبهم/ناقص برای یادآوری به پزشک `p1`
- **#6** [infra] صف پردازش ناهمزمان (Queue) برای درخواست‌های ساعات شلوغ `p1`

## اپیک ۲ — کلاینت پزشک (Web)

- **#11** [feature] نمایش «خلاصهٔ تغییرات از ویزیت قبلی» در شروع ویزیت جدید `p2` (وابسته به #21)
