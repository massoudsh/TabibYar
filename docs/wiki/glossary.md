# واژه‌نامهٔ بالینی-فارسی

این واژه‌نامه برای هم‌راستا نگه‌داشتن تیم فنی و پزشکی روی معنای دقیق اصطلاحات ساختاریافته است.

| اصطلاح | معنی در این محصول | معادل رایج بالینی |
|---|---|---|
| شرح‌حال | روایت بیمار از علت مراجعه، سابقه و علائم | History / Chief Complaint |
| یافته‌های مهم | مشاهدات عینی پزشک در معاینه یا آزمایش | Findings |
| تشخیص احتمالی | فهرست پیشنهادی AI — **همیشه نیازمند تأیید پزشک، هرگز نهایی** | Differential Diagnosis (Draft only) |
| برنامهٔ درمان | تصمیم درمانی پزشک شامل دارو/اقدام | Treatment Plan |
| توصیه | راهنمایی قابل‌فهم برای بیمار (زبان ساده، نه فنی) | Patient Instructions |
| هشدار | نشانه‌هایی که در صورت بروز، بیمار باید فوراً اطلاع دهد/مراجعه کند | Red Flags / Warning Signs |
| پیگیری | اقدام یا زمان مراجعهٔ بعدی مشخص‌شده توسط پزشک | Follow-up Plan |
| پروندهٔ بیمار | مجموعهٔ کامل ویزیت‌ها، یادداشت‌ها و پیگیری‌های یک بیمار | Patient Record / EHR |
| حافظهٔ درمان | تجمیع روند علائم، دارو و پاسخ بیمار در طول زمان (لایهٔ فاز دو) | Longitudinal Treatment History |
| پیش‌نویس AI | خروجی خام مدل قبل از تأیید پزشک؛ هرگز به‌عنوان سند نهایی نمایش داده نمی‌شود | AI Draft |
| یادداشت تأییدشده | نسخه‌ای که پزشک ویرایش و تأیید کرده و در پرونده ثبت می‌شود | Signed Note |

## نکتهٔ حیاتی زبانی

گفتار واقعی پزشک ایرانی معمولاً **نیمه‌رسمی** و آمیخته با اصطلاحات لاتین/انگلیسی است (مثلاً «BP بیمار ۱۴۰ رو ۹۰ بود»، «قرص متفورمین رو ادامه بده»). پرامپت‌های ساخت‌دهی باید این آمیختگی را به‌عنوان ورودی طبیعی بپذیرند، نه فقط فارسی خالص را.
